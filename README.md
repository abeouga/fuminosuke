## 製品の目的

Excel帳票と記入画像を使い、OCR候補を人が確認・修正したうえで、処理結果をExcelへ戻してダウンロードできるようにします。帳票ごとに読み取る欄・識別情報・表の列と行を設定する汎用の帳票OCR変換ツールです。

```text
.xlsxをアップロード
  → Excel帳票からテンプレートを作成
  → テンプレートを選択して帳票画像を読み取る
  → OCR候補を確認・修正
  → 結果を明示的に確定
  → 処理済み.xlsxをダウンロード
```

ページ構成とテンプレートの対応を検証できる場合は、専用の複数ページ経路を利用します。全ページの値と切り出し画像を確認し、必要な修正を保存してから確定します。

画像から作成したテンプレートにも対応します。新規画像テンプレートは固定の業種別項目を持たず、設定した項目・表の構造に沿ってXLSXを生成します。原XLSXがある帳票は既存の原本へ値を反映する出力経路を優先します。

書類の識別確認は、テンプレートで選んだ番号・名称・日付等に従います。すべての帳票へ個体識別番号や10桁制約を要求しません。保存済みデータは汎用schema 2.0へ変換済みです。旧業種schemaと旧API形式の互換処理はありません。

## v0.1の対象範囲

- `.xlsx` のアップロードと、Excel帳票に基づくテンプレート作成
- 空の帳票画像に基づくテンプレート作成と、独立項目・明細表のXLSX出力
- テンプレート版の確認・編集・有効化
- 帳票画像からのOCR候補生成
- OCR値と対応する切り出し画像の確認、利用者による修正
- 確定結果を対応するExcelセルへ反映した `.xlsx` のダウンロード

## v0.1で提供しない機能

- Google Drive / Google Sheets、OneDrive、Dropbox等との入出力・同期
- OCR結果の履歴検索、横断検索、管理ダッシュボード
- カメラ撮影
- あらゆるExcelレイアウトやレンダラー差異への完全対応
- OCR結果の自動確定、人間による確認を省く運用

Google認証・同期、検索、書類ライブラリ、バックアップUI、開発情報画面、業種別モデルは実行経路と公開APIから廃止しました。結果の確認・修正・確定・XLSX取得を提供します。

## OCR結果とデータ対応の原則

OCR結果は確定値ではなく、確認・修正が必要な候補です。文字列だけで正しさを判断せず、入力ページ、帳票上の物理セル、mapping、切り出し画像、レビュー項目、出力先の対応を維持します。

- 対応先が曖昧な結果を隣の欄へ推測で割り当てません。
- 補正はrevision付きで保存し、競合や再取得時にも利用者の修正値を保護します。
- 全ページの明示確認と確定を終えるまで、確定済みの出力として扱いません。
- OpenAIを設定した場合、外部OCRには設定済み欄の切り出し画像が送信されます。provider、送信範囲、失敗時の扱いは [OCR Safety Contract](docs/ocr-safety-contract.md) を参照してください。

## 操作アシスタントの使い方

OCR結果で修正する欄、または編集中のテンプレートで変更するセルを選び、
「操作アシスタント」を開きます。未保存の手動編集がある場合は、先に保存または明示的に破棄してください。
OCR値の変更、下書きテンプレートのセル名称・対応可能な分類・選択肢名称の変更に使用できます。
複数項目の一括変更、対象の選び直し、書類の確定は音声指示の対象外です。

1. 「音声入力」を押し、マイクを許可します。「録音中」と表示されてから、
   例えば「選択した欄をゼロゼロいちにさんに変更」と話し、「録音を終了して送信」を押します。
   文字による指示を使う場合は「変更指示」に入力して「指示を送る」を押します。
2. 原本・対象・変更前後を確認します。変更案を作成しただけでは保存されません。
   先頭ゼロや名称は、表示された保存文字列で確認してください。
3. 音声で承認する場合は「変更案を読み上げ」を押し、最後まで聞きます。
   再生終了後に「音声で承認」を押して「変更を適用」と話し、録音を終了して送信します。
   画面で承認する場合は、案を確認して「変更を適用」を押します。
4. 保存完了の表示と更新された値を確認します。「保存結果を読み上げ」でも結果を聞けます。
   読み上げの失敗だけで、成功した保存が取り消されることはありません。
5. 直前の変更を戻す場合は「取り消し案を表示」で復元内容を確認します。
   音声承認では案の読み上げ完了後に「音声で承認」から「取り消しを適用」と話します。
   または案を確認して「取り消しを適用」を押します。

変更指示は自然な文章を使えますが、音声承認は上記の固定句を使用します。
「はい」「承認する」「それでよろしく」などの返答では保存しません。録音の中止や読み上げ停止でも保存しません。
案は120秒で失効し、選択・編集状態の変更でも無効になります。失効時は案を作り直してください。
保存後に手動編集・確定・再編集・テンプレート公開などを行った場合、直前の取り消しが拒否される場合があります。

音声はOpenAIの文字起こしへ、指示と選択項目の表示名・現在値・許可操作は変更案の抽出へ送信します。
読み上げはAI音声です。原本画像や全テンプレートを音声操作APIへ送らず、
生音声と会話全文を通常DB・ログへ保存しません。1回の録音は60秒以内、10MiB以内です。
マイク・音声設定・残りAPI枠を使用できない場合は、型付きの手入力と案の確認・適用を使用してください。
外部AI APIの累計上限は100回で、失敗や再起動でも消費数を戻しません。

保存結果が不明と表示された場合は「保存結果を確認」を使用し、結果が判明するまで
新しい変更を重ねないでください。OCR値を保存しても書類全体は確定しません。
全項目を確認した後、結果画面の「確認して確定」で確定してからXLSXを取得します。

## 現行のデータ形式

- OCR結果：schemaVersion `2.0`、`fields`、`fieldLabels`。保存先は `fields.<key>`。
- 識別情報：テンプレートの `documentIdentityFields`。番号・名称・日付・組合せを確認します。
- テンプレートパッケージ：format/schemaVersion 2。旧package v1は取り込めません。
- DB初期導入：`generic_schema_v2`。旧DBへの実行時upgradeや値の再構築は行いません。
- 出力：確定した `.xlsx`。原XLSXのセルbinding、または受付時reviewStructureを使用します。

既存の補正・確定値とcrop対応は一回限りの変換で保持しました。変換器・旧DB・退役コード・
使い捨て検証は `D:\llm-ocr-archive\generic-cleanup\20261004` に退避しています。
現行仕様と検証は [互換廃止・汎用変換記録](docs/generic-cleanup-2026-10-04.md) を参照してください。

## 検証状況と制限

READMEに記録されていた数値は固定合成画像1件による退行検知結果です。実帳票のOCR精度、利用者の修正量・確認時間、外部OCR方式の比較を証明するものではありません。実帳票評価や30件以上の匿名化Goldenデータは、文書上まだ整備・確認されていません。自動確定や精度保証を示す数値として使用しません。

変更時は [AGENTS.md](AGENTS.md) と [OCR Safety Contract](docs/ocr-safety-contract.md) に従い、変更範囲に応じた最小の必須検証を選びます。OCR・mapping・crop・補正・出力対応に関する変更では、同契約のOCR-sensitive検証を適用します。テスト結果、実帳票での精度、クラウド本番運用の確認は、それぞれ別の証拠として扱います。
