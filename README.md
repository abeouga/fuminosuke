## 主な機能
1. **テンプレートを作る**：原本の .xlsx からも、空の帳票の画像からも作れます。業種ごとに決まった項目は持たず、どの帳票にも同じ手順で使えます。
2. **読み取って、人が確定する**：OCR の結果を切り出し画像と見比べて直し、確かめてから確定します。
3. **書き足した分だけ読み直す**：後から書き足した内容を新しい版として取り込み、前の版と人が直した値を残します。
4. **チャットで質問する**：確定した値だけで答えます。答えには元の書類と欄が付き、該当するセルを枠で示します。
5. **音声で直す**：選んだ欄やセルへの変更を、声か文字で頼めます。承認したときだけ保存します。
6. **MCP で他の AI に渡す**：確定した値と書類の画面を、Agorack（複数のシステムをまとめて質問に答えるチャット）などから使えます。

## 何をするか

```text
帳票（.xlsx または空の帳票の画像）からテンプレートを作る
  → テンプレートを選んで、記入した帳票の画像を読み取る
  → 読み取った値（OCR の候補）と切り出し画像を見比べて、確かめ・直す
  → 確定する
  → 値を反映した .xlsx を取り出す ／ チャットとライブラリで確定した値を見る
```

- テンプレートは、帳票ごとに、読み取る欄・書類を見分ける欄（番号・名称・日付など）・表の列と行を決めたものです。業種ごとの決まった項目は持ちません。
- 原本の .xlsx がある帳票は、原本のセルへ値を書き戻します。画像から作ったテンプレートは、決めた欄と表の形のとおりに .xlsx を作ります。
- 複数ページの帳票は、ページの組み立てとテンプレートの対応を確かめられる場合に、全ページの値と切り出し画像を確かめてから確定します。

## 画面

| 画面 | できること |
|---|---|
| チャット | 確定した値について質問する（例：「毛色が黒の牛は何頭か」）。答えには、どの書類のどの欄から取ったかが付き、押すと書類の確認画面で開く |
| 読み取り | テンプレートを選び（作り・直すのもここ）、帳票の画像を読み取って、確かめ・直し・確定する |
| ライブラリ | 読み取った書類の一覧。書類を開いて値を確かめる |
| 修正率 | 読み取った値を人がどれだけ直したか（管理者だけに出る） |

## 読み取った値の扱いの原則

OCR の結果は確定値ではなく、人が確かめて直す候補です。文字だけで正しさを決めず、入力のページ、帳票の上のセル、欄との対応、切り出し画像、確かめる項目、出力先の対応を保ちます。

- 対応先があいまいな結果を、推測で隣の欄に割り当てません。
- 直した値は版を付けて保存し、ぶつかったときや読み直したときにも、利用者が直した値を守ります。
- 全ページを確かめて確定するまで、確定した出力として扱いません。
- チャットと MCP サーバーは、確定した値だけを返します。値を作ったり言い換えたりせず、計算は集計の処理に任せます。

## 音声の操作アシスタント

読み取った値を直す欄、または編集中のテンプレートのセルを選んで「操作アシスタント」を開くと、声か文字で変更を頼めます（例：「選択した欄をゼロゼロいちにさんに変更」）。

- 変更の案を出すだけでは保存しません。原本・対象・変更前後を確かめてから、画面のボタンか、決まった言葉（「変更を適用」「取り消しを適用」）で承認したときだけ保存します。「はい」などの返事では保存しません。
- 直前の変更は、取り消しの案を確かめてから戻せます。
- 声は OpenAI の文字起こしへ、指示と選んだ項目の名前・今の値・できる操作は、変更の案を作る処理へ送ります。原本の画像やテンプレートの全体は送らず、録音と会話の全文はデータベースとログに保存しません。
- 1 回の録音は 60 秒以内、10MiB 以内です。
- 値を保存しても、書類は確定しません。確定は、結果の画面の「確認して確定」で行います。
