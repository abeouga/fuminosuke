## 主な機能
1. **OCR用テンプレートを作る**
  <br>書類の原本となる .xlsxでも、印刷された実物の書類からでもテンプレートを作成することができます。<br>これにより<ins>AIのOCR特有の解釈の揺れ</ins> が起きづらくなります。
  >従来のAIOCRは、<ins>*書類がもつ記入欄とその記入欄がどこの見出しに紐づいているかを保障できない*</ins>ので、文字が読めたとしてもそのデータをどうやってのちの活用につなげづらいのが課題でした。
  ><br>それに加えて<ins>*同一の型の書類でもOCRするたびに結果が変わってしまう*</ins>という問題があります。(解釈の揺れ)
  
2. **読み取り後の確認**
   <br>OCR の結果と元の画像を<ins>人の手</ins>で比較して修正。
6. **音声操作**<br>テンプレート作成とOCR結果の修正を音声操作、またはプロンプトで行えます。
4. **書き足した分だけ読みとる**<br>同一の書類をOCRする際は後から書き足した内容(差分)のみを取り込みます。
5. **チャットでデータを取り出す**<br>OCR結果をチャット形式で取り出すことができます。<br>回答は元の書類とセットで回答され、該当するセルを枠で強調表示します。
7. **MCP で他の AI に渡す**<br>読み取り結果を AIが利用できる形で保存して取り出せるようにしているので、<br>Agorack（自作のAIチャットシステム）からも 文之助内のデータを利用できます。<br>
  >Agorackは文之助やドライブロガーが所有するデータや機能を MCP経由で利用することができる RAG型AIチャットです。<br>テンプレート作成やOCR結果の修正は文之助側で行い、OCRシステムの利用やデータの取り出しは Agorack側で行うことを想定しています。
