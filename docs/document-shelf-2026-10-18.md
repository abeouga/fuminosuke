# 書類棚（確定済みの書類の閲覧）2026-10-18

## 目的と範囲

利用者指摘「OCRした後の結果を閲覧できない」に対応。確定済みの書類を、疑似的なファイルのように
テンプレート（フォルダ）ごとに並べ、開くと読み取り専用で内容を表示する。

利用者の決定：

- フォルダ＝テンプレート、ファイル＝確定済みの書類（系列の最新版だけ）。
- 確認待ち（未確定）の書類は出さない。ホームの「対応が必要な処理」に残す。
- 前の版の閲覧は後回し。
- 値を押すと原本の該当箇所（欄の切り抜き画像）を表示する機能は最初から入れる。
- 修正とXLSXは既存の画面・経路を使う。

2026-10-04の記録では「書類ライブラリ」は製品対象外だった。今回は利用者の明示要求により、
確定済みデータの読み取り専用の閲覧に限って対象へ戻す（バックアップUI・同期・書類の削除/移動は含めない）。

## 実装

- 画面：`frontend/src/pages/ShelfPage.tsx`、`frontend/src/shelf.css`。サイドメニュー「書類棚」、
  アドレス `?view=shelf&doc=<jobId>`（再読み込みでフォルダと書類が戻る）。
  - 左：テンプレート（確定日の新しい書類があるものから順）。名称は現在のテンプレート名、無ければ確定時の名前。
  - 中：書類一覧。名前は確定時の書類名、無ければ識別値。検索は全フォルダ横断（書類名・識別値・テンプレート名）。
  - 右：識別値、基本項目・見出しごとの欄、表、その他の読み取り値。値を押すと上部に原本の切り抜きを表示し、
    「確認画面でこの欄を開く」で既存のレビュー画面へ（その欄を選んだ状態）。
  - 「修正する」は既存のレビュー画面を開く（確定済みのため、修正は画面の「再編集」から）。戻るボタンは「書類棚へ戻る」。
  - XLSX：単一画像は既存の `ExcelExportActions`（`/api/v1/ocr-jobs/{id}/export`）、ページ別は既存の
    `api.downloadPageOutput(id, confirmedRevision)`。
- API：`GET /api/v2/structured/documents/{jobId}` の各欄に `cropUrl` を追加（追加のみ、既存項目は不変）。
  URLは質問応答の根拠と同じ `fieldCrop.<fieldId>.alignedColor`（ページ別は `page.<pageId>.` 付き）で、
  生成は `structured/service.field_crop_url` に一本化し、質問応答の `_crop_url` もこれを呼ぶ。
- 一覧・詳細は既存の構造化投影（確定の判定はレビュー/出力と同じ）をそのまま使う。書き込みなし。

OCR値・mapping・crop・revision・確定・出力は変更していない（既存OCR contractを維持）。

## デザイン改善：サムネイルと原本ビューア（同日）

利用者指摘「サムネとか実画像があったほうがわかりやすい」に対応。

- 一覧：書類をサムネイル付きのカードで並べる（原本の1ページ目、確定日・版・識別値）。検索は全フォルダ横断で、カードにフォルダ名を表示。
- 書類を開くと全幅表示（フォルダ列を隠し、「← フォルダ名」で戻る）。左に原本ビューア、右に読み取り値。
  - 原本ビューア：位置合わせ済みのページ画像に、読み取った全欄の枠を重ねる。値を押すと枠を強調してその位置までスクロールし、枠を押すと右の値を強調してスクロールする。拡大100/150/200/300%、複数ページはページ切替。
  - ビューアの下に選んだ欄の場所・値・切り抜き画像と「確認画面で開く」。
  - 1180px以下では原本を上部に固定し、値の一覧だけがスクロールする（スマホは原本の高さを34dvhに抑える）。
- API（追加のみ、既存項目は不変）：
  - `GET /api/v1/jobs/{id}/artifacts/{name}/thumbnail?width=360`：画像成果物の縮小JPEG（120〜800px、ETag=成果物SHA＋幅、304再検証）。成果物の取得処理は既存の `get_artifact` と共通化（`_artifact_file`）。
  - 構造化の一覧に `thumbnailUrl`、詳細に `pages`（ページID・番号・位置合わせ済み画像URL）と各欄の `box`。`box` はレビュー画面の欄プレビューと同じ規則（読み取りに保存された位置、無ければmappingの矩形）。
- 検証：複製データ（確定11件）でサムネイル11件（17〜45KB、19〜56ms、304再検証）、全816欄に `box`。1280px/375pxの実画面で、値→枠、枠→値、拡大300%時の追従、スマホの固定表示で値が隠れないこと、横はみ出し・コンソールエラーなし。build・vitest177、ruff/format通過。通常サーバーを21:04に再起動し、通常DBの3件でサムネイル・原本・欄位置（82欄）を確認。
- 未確認：ページ別（paged）書類のページ切替（複製データに無い）。
