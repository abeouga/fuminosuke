# テンプレート選択・作成UIの調整（2026-10-05）

## 原因と変更

- 選択カードの210px最小幅、2列の長い操作名、overflow-wrap:anywhereの組合せでボタン内が不自然に改行されていた。
- OcrTemplateSelector.tsx: 操作を「複製・編集・削除」に短縮。対象名を含むアクセシブル名・処理・disabled条件は維持。
- workbench.css: カード最小幅280px、3操作を1行、印刷ボタンの改行を抑制。狭い画面ではカード自体を1列にする。名前は省略せず表示。
- TemplatePage.tsx: 作成画面を「原稿の種類・ファイル・名前」の順に配置。準備方法にアイコン・選択マーク・aria-pressedを追加。
- LayoutEditor.tsx: 読み取り方法を1列に配置し、選択状態を強調。記号・印刷選択肢の文言を短縮。

## 変更境界

表示・文言・DOM配置の変更。API payload、入力の検証条件、保存処理、mapping、crop、OCR、revision、有効化条件を変更していない。既存OCR contractを維持した。
