# Google Sheets直接修正の設定

このスクリプトは、OCRアプリが作成したGoogleスプレッドシートの通常セル編集を
非表示の `_OCR編集キュー` へ記録します。ローカルOCRアプリは既存のGoogle OAuthで
このキューを読み取り、SQLiteのOCR結果へ反映します。

## 台帳ファイルごとの初回設定

1. OCRアプリが作成したスプレッドシートを開きます。
2. `拡張機能` → `Apps Script` を開きます。
3. `Code.gs` の内容をこのフォルダの `Code.gs` で置き換えて保存します。
4. 関数一覧から `setupOcrSheetEditing` を選んで1回実行します。
5. Googleの権限確認を完了します。

OCRアプリは台帳ごとに別のスプレッドシートを作成します。この設定は、自動作成された各スプレッドシートで1回ずつ行ってください。Drive/Sheetsの必要最小限の権限では、Apps Scriptプロジェクトとインストール型トリガーをアプリから自動付与できません。

以後、帳票一覧・売却子牛一覧・繁殖履歴の通常データセルを編集すると、ローカル
アプリが既定5秒間隔で変更をDBへ取り込みます。`status`、ジョブID、修正リンク、
非表示メタデータ列は編集対象ではありません。

矩形、認識領域、ラベル対応を変更する場合は、各行の `修正` リンクからReactの
詳細修正画面を使用します。確定済み結果でも、リンクから開くと対象セルを選択した
再編集状態になります。更新後のリンク式を反映するには、アプリから対象帳票を一度
スプレッドシートへ再出力してください。
