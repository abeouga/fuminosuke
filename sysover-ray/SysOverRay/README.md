# SysOverRay

`llm-ocr-deploy` のバックエンドとフロントエンドを、Windowsデスクトップ上の小型オーバーレイからまとめて起動・停止・再起動するツールです。

## 使用方法

1. 親フォルダーの `SysOverRayを起動.lnk` を開きます。配置先は `../app/SysOverRay.exe` です。
2. 「起動」「再起動」「停止」のいずれかを押します。
   - 「関連ポートを全停止」は、確認画面を表示した後、設定範囲内で待受中のプロセスをまとめて停止します。
3. `×` は画面を隠すだけです。再表示またはアプリ終了はタスクトレイのアイコンから行います。

アプリを終了しても、既に起動している `llm-ocr-deploy` は停止しません。ブラウザーは「ブラウザを開く」で開きます。


## 対象

- 起動ショートカット: `sysover-ray/llm-ocr-deployを起動.lnk`
- 起動処理: `sysover-ray/Start-LlmOcr.ps1` → `scripts/dev.ps1`
- プロジェクト: この `sysover-ray` を格納している `llm-ocr-deploy`
- バックエンド確認: `http://127.0.0.1:8010/api/v1/health`
- フロントエンド: `http://127.0.0.1:5180`

値を変更する場合は、実行ファイルと同じ場所の `app/overlay-settings.json` を編集します。`ProjectRoot` は検出したプロジェクトルートを基準に、`ShortcutPath` は解決した `ProjectRoot` を基準にした相対パスを使用できます。起動処理も同じ設定からポートを読みます。

Google連携は製品から廃止しました。起動設定に認証・同期の切替はありません。OCR providerとmodelはbackendの設定を使用します。

起動時にfrontendの許可originとAPIプロキシを5180・8010へ合わせます。別アプリが使用している5173・5174には接続・停止要求を送りません。

## 安全上の制約

通常の「停止」は、デプロイ側の起動コントローラーとbackend/frontendのプロセスツリーを停止します。起動・停止時の専用ポート清掃は、コマンドラインと生存する親プロセスを照合し、設定プロジェクトの所有者だけを停止します。別プロジェクトの所有者がいる場合は、停止せずエラーにします。

「関連ポートを全停止」の対象は、今回の設定ではフロントエンド `5180`、バックエンド `8010` だけです。この明示操作はプロジェクト照合を行わず、確認画面で示す範囲の所有者を停止します。範囲を広げると別アプリも対象になるため、通常の停止とは区別してください。

両サーバーを一体で監視するため、個別再起動は提供しません。再起動は残留コントローラーの停止を含めてから、両サーバーを起動します。

## 開発用ビルド

```powershell
dotnet build .\SysOverRay.csproj
```

## 配布用出力

```powershell
dotnet publish .\SysOverRay.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o ..\app
```
